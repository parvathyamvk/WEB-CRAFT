## About the Project

WEB-CRAFT is a small personal landing-page project built using HTML, CSS, and JavaScript. The page introduces **Parvathy A**, displays a short description about learning and exploring web technologies, and provides a contact button linking to Instagram.

The page also uses JavaScript to periodically switch the displayed role between **UI/UX Designer** and **Web Developer**.

## Features

- Personal introduction with the name **Parvathy A**.
- Profile photograph displayed on the page.
- Short description about learning, technology, and development.
- Contact button linked to the Instagram profile.
- JavaScript-based rotating role text.
- CSS styling with a dark background, accent-colored heading, and hover effect on the contact button.
- A media query for smaller screens.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Layout, colors, typography, hover effect, and responsive styling |
| JavaScript | Randomly changes the role text at regular intervals |

No external libraries or package installation are required.

## How to Run Locally

### Prerequisites

- A modern web browser such as Chrome, Firefox, or Edge.
- A code editor such as Visual Studio Code (optional).

### 1. Clone the Repository

```bash
git clone https://github.com/parvathyamvk/WEB-CRAFT.git
```

### 2. Open the Project Folder

```bash
cd WEB-CRAFT
```

### 3. Run the Website

Open `index.html` in your web browser.

You can also open the folder in Visual Studio Code and use the **Live Server** extension to preview the page while editing.

## How the Role Text Changes

The JavaScript file contains two role descriptions:

- UI/UX Designer
- Web Developer

A function selects one of the descriptions randomly, and `setInterval()` updates the heading every second.
